---
name: Card catalog pricing
description: How to determine values for newly added hockey cards.
---

Do not guess or invent a catalog value for a new card. Check for an explicit
user-provided value or a documented deterministic pricing rule; if neither
exists, ask for the value. Pack prices and individual card values are separate.

**Why:** The user requires catalog values to follow existing rules rather than
being invented, and a card's value is used by the sale system.

**How to apply:** Before adding a card to the seed catalog or live SQLite
database, confirm its explicit sale value or the pricing rule that determines it.
